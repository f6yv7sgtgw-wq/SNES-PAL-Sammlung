# SNES PAL Sammlung 0.2

## Ziel der Version

Version 0.2 ist ein privater Sammlungsmanager für PAL-Veröffentlichungen des Super Nintendo Entertainment System.

## Enthaltener Umfang

- 530 PAL-Spiele
- Sammlung und Katalog als zentrale Bereiche
- lokale Speicherung im Browser
- Import und Export der persönlichen Sammlung
- Marktwerte für mehrere Zustandsvarianten
- keine Wunschliste
- keine Deals
- keine Preisalarme

## Datenstand

- 530 von 530 Spielen geprüft
- 2.647 von 2.650 Zustandswerten aktualisiert
- 3 Werte ohne verfügbare Marktdaten

## Preisquellen

- PriceCharting PAL SNES
- Umrechnung auf Euro mit dem ECB-Tageskurs vom 28.07.2026

## Bekannte Einschränkungen

- lokale Daten sind an Browser und Gerät gebunden
- ohne Export können Browserdaten verloren gehen
- die bestehende veröffentlichte Version wurde noch nicht als vollständiger Originalbuild in dieses Repository übernommen
- die derzeitige Repository-`index.html` bildet den 0.2-Stand nicht vollständig ab
